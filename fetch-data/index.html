Fetch Data Example

The page demonstrates JavaScript's fetch() function. Fetch uses JavaScript's async/await interface.

This page fetches the data from your data URL once every ten seconds. It assumes your data is a text file, with one JSON object in each line. If you click "Display Data" it will display all the data obtained as of the last fetch. You can change the URL at any time.

How Fetch Works

Fetch works by making an HTTP request in a Promise, then awaiting a response. A successful response returns a Response object. You usually convert the response to the data form you want, and then use that result in your script.

You might also need to catch an error if there is one, or you might need to set some parameters, like the headers of your HTTP request, or whether or not to permit CORS requests, and so forth. You can see examples of these in this page's script, which is embedded in the HTML.

For more info, see MDN's documentation on using fetch.
